# 웹툰 리뷰 애플리케이션

## 프로젝트 소개 ##
웹툰을 좋아하는 사람들을 위한 애플리케이션입니다.
- 남녀별 인기 웹툰을 조회할 수 있습니다.
- 웹툰 별 자유롭게 채팅할 수 있습니다.
<br><br>

## 개발 환경 ##
- Back-End
 - Java 17, Spring Boot 3.3.1, Spring JPA, Spring Security
- Android
 - Kotlin 1.9
- STOMP
